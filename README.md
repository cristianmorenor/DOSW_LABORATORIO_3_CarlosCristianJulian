#Preguntas iniciales


## ¿Qué es un Pull Request en GitHub?

Un Pull Request (PR) es una solicitud para integrar los cambios de una rama a otra. Permite que otros miembros del proyecto revisen los cambios antes de integrarlos.

## ¿Cómo se crea un Pull Request en GitHub?

1. Crear una rama y realizar los cambios.
2. Hacer `commit` y subir los cambios con `push`.
3. Entrar al repositorio en GitHub y seleccionar Pull requests.
4. Hacer clic en New pull request.
5. Seleccionar la rama de origen y la rama de destino.
6. Escribir una descripción y seleccionar Create pull request.

## ¿Cómo se aprueba un Pull Request en GitHub?

1. Entrar al Pull Request.
2. Revisar los cambios realizados.
3. Seleccionar Review changes.
4. Elegir Approve y confirmar la revisión.

Después de ser aprobado, el Pull Request puede hacerse merge para integrar los cambios.
